# Circle_Solutions

Merged website: the individual team pages share one header (from About Us), one footer
(from the Homepage) and a single `general.css` with the shared colour palette.

## Pages

- `index.html` — Homepage
- `about.html` — About Us
- `about-nl.html` — About Us (Nederlands)
- `solutions.html` — Solutions
- `contact.html` — Contact

### Nederlands

- `index-nl.html` — Homepage
- `about-nl.html` — Over ons
- `solutions-nl.html` — Oplossingen
- `contact-nl.html` — Contact

The language switch in the shared header links each page to its translated version.

## Styles

- `general.css` — fonts, shared colours, common header and footer
- `homepage.css`, `about.css`, `solutions.css`, `contact.css` — page-specific styles only

## Assets

- `assets/fonts` — Calibre font files
- `assets/images` — images used by the merged pages

The original team folders (`aboutUs/`, `homepage/`, `solutions/`, `contact/`) are kept
unchanged for reference.
